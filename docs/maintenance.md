# 维护与路线

## 项目范围

本仓库维护数模主控、建模、写作、图表及辅助工具，并提供只读的本地 Harness 工作台。不同技能的能力和依赖见[技能目录](skill-catalog.md)；`99-creative-writing` 是独立分类，不是数模流程的前置条件。

## 当前状态

- `main` 上的主控为开发快照：版本标识统一为 4.18，包含尚未发布的 H4/H5 合并改动；完整发布检查尚未通过。
- GitHub Actions 检查仓库结构、合成示例、工作台，以及 Harness / MathorCup 的重点行为。健康检查支持分类仓库与平铺技能目录，但仓库内找到技能包不代表宿主已经安装；完整严格检查的限制及复现命令见[验证说明](validation.md)。
- 工作台读取已有 Harness 项目；角色会话链接需要用户登记和核实。当前不提供团队远程共享、工作台内聊天或自动审批。
- 公开示例和回归数据不能替代实际竞赛数据、独立验证、论文编译或人工批准。

## 待改进方向

1. **公开包完整性：** 分别验证仓库打包和宿主安装状态；私有经验库不随包发布，缺失时按冷启动处理。完成发布验证前不宣称稳定版。
2. **上手体验：** 根据可复现反馈完善安装、宿主兼容说明和小型示例；已有技能不应被安装命令静默覆盖。
3. **工作台可靠性：** 在不修改比赛数据的前提下改进真实记录的读取、同步与预览；角色可访问性和审批结果以实际记录及用户核实为准。
4. **验证覆盖：** 针对发现的真实故障补充回归检查，并区分本地测试、CI、外部工具和实际比赛使用的验证范围。

以上是维护方向，不承诺具体发布日期。欢迎通过 [Issues](https://github.com/cjh-solver/MathModeling-Skills-Arsenal/issues) 提交可复现的问题，或按[贡献指南](../CONTRIBUTING.md)提交改进。

## 维护检查

每次更新前核对目标分支与待提交内容；只同步确认可公开、与本仓库兼容的文件。更新技能时保留原名称与第三方许可证，避免把本机路径、会话登记、真实竞赛材料或凭据带入仓库。执行受影响测试和 `python scripts/check_repository.py`，在变更说明中区分通过、未运行和已知失败项。

版本、路由或跨技能接口变化需同时检查文档、引用方与测试；只有经过完整发布检查后才更新稳定版声明。变更记录见 [CHANGELOG](../CHANGELOG.md)，代码历史与 CI 可从 GitHub 的 Commits 和 Actions 页面查看。
