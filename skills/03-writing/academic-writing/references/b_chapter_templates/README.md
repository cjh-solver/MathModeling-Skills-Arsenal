# B题建模求解章节模板库

按近五年（2021-2025）国赛B题归纳的建模求解章节基本框架。拿到题目先逐问判定形态，再按形态取对应模板文件。模板只规定"写什么内容"，不规定"用什么模型/算法"——具体方法由做题时决定。

## 使用流程

1. 数大问数。2问结构只用 problem1、problem2；4问结构全用
2. 逐问判定形态，查下方判定表定位
3. 取对应形态文件，按骨架结构填充
4. 共享模块引用 shared/（衔接句、结果格式等）
5. 所有问题统一遵守本页的"统一写作硬约束"

## 统一章节骨架（所有形态优先遵守）

每个问题标题后先写一段不编号的问题引入与建模思路，交代题目任务、已知条件、关键困难、输出目标及与前后问题的关系。随后只设置两个编号小节：

```text
5.x 问题x：[问题核心概括]
  问题引入与建模思路（不编号）

5.x.1 模型建立
  假设、局部符号、必要推导、目标/状态关系、约束/边界
  最终模型或结论（小节末尾的框式表达）

5.x.2 模型求解与结果分析
  算法、参数、实现条件、主要结果、结果意义、可靠性和适用范围
```

"决策变量、目标函数、约束条件、推导、算法、结果分析"等只能作为小节内的无编号加粗引导词。独立的灵敏度/稳健性小节仅在存在独立扰动证据时添加，否则并入 `5.x.2`。全局符号只在前置"符号说明"章节集中登记，局部新符号在首次出现处定义。

## 形态判定表

### 问一类型判定
- 机理建模：物理/几何关系明确，推导建立模型，如2022、2023、2025
- 数据拟合：关系未知，由数据回归/插值建立，如2021
- 统计决策：按风险/信度做方案设计，如2024

### 问二与问一的关系判定
- 承接扩展：加参数/加条件，复用原模型，如2023、2025
- 平行推广：换场景，模型结构不变，如2022
- 并列模块：独立建模，仅沿用问一数据或结论，如2024、2021

### 问三类型判定
- 优化决策：目标函数+约束+最优方案，如2021、2023
- 推广型：从特例推广到一般情形，或深入机理扩展，如2024、2025

### 问四类型判定
- 重做型：条件变化后全流程重跑，或模型修正+重算，如2024、2025
- 综合应用：真实数据/复杂场景应用，或实验设计，如2023、2021

## 统一写作硬约束（所有问题必须遵守）

1. **问题引入段**在节标题下，直接位于5.x标题之后，不设置编号，1段说完问题要求、已知条件、关键困难、输出目标、与前后问题关系
2. **先判定形态再写**，不要混用
3. **复用前问模型**时写清被复用公式/模型的含义、变更范围和本问新增推导，不重复展开已经成立的关系，只推导新增部分
4. **公式规范**：每个公式前有文字引导，后有解释；连续公式不超过3个，超过必须插入文字解释
5. **2级标题**必须包含具体内容，不能只用"模型的建立""模型的求解"
6. **结果分析**必须解读数值含义，不能只罗列数值；分点分析，每个点有明确主题
7. **算例验证**必须有，模型只推导不落地是常见扣分点；问题1至少2个算例，问题2/3/4至少1个
8. **最终模型/结论**用框式表达（boxed或类似），放在模型建立小节末尾，直观说明得到了什么
9. **配图**：关键推导步骤配图，图前有文字提出观察目标，图后有文字说明其对推导的作用；图题在下方，表题在上方
10. **篇幅控制**：问一约占全文25%-30%，问二约20%，问三约25%，问四约20%
11. **段落长度**要有变化，不能每段都是3句话，长短句结合
12. **反机械**：不写"首先...其次...然后...最后..."这种四个的机械列表连接词；不用空泛价值判断
13. **某问含(1)(2)**时，在同一个 `5.x.1` 和 `5.x.2` 中用无编号加粗引导词区分子问，不新增碎片化编号层级
14. **结果格式**：按题目要求的表格格式输出，需要保存的结果文件按题目要求命名
