# 数模工作台

一个面向已有 Harness 比赛项目的本机只读工作台：集中查看阶段、小问、角色会话、资料、图表、论文和已有审查记录。它读取本地项目文件并定时刷新，不调用模型维护页面。

## 安装与启动

需要 Python 3.13 和 PyYAML。PDF、Word、Excel 预览分别需要 PyMuPDF、python-docx、openpyxl：

```powershell
py -3.13 -m pip install PyYAML PyMuPDF python-docx openpyxl
cd tools/harness-workbench
py -3.13 app.py --open
```

Windows 也可以双击 `start_workbench.bat`。使用期间保持终端窗口打开；关闭窗口后服务停止。若浏览器没有自动打开，访问 http://127.0.0.1:8765/。

没有现成项目时，可以先使用[合成演示项目](../../examples/workbench-demo/README.md)体验页面。

## 比赛中使用

1. 先用已安装的 `contest-orchestrator` 创建或选择一个 Harness 比赛项目，确认项目根目录有 `.contest/harness_control.yaml` 且模式为 `full-contest-harness`。工作台本身不创建比赛项目。
2. 启动工作台，点击搜索框旁的“＋”，输入该比赛项目根目录。之后可在搜索框中切换已发现或已添加的项目。
3. 通过“比赛流程”查看 H 阶段及其已登记输入、输出与审批记录；在“小问管理”“资料与文献”“图表与成果”和“论文工作区”查看已有资料。
4. “角色会话”可以登记真实的 Codex 会话 ID，再尝试从工作台打开。角色 ID 不能当作会话 ID；链接是否可访问需要实际确认。
5. 保持页面可见时，每 10 秒读取项目；连续两次结果一致后显示变化。输入或展开详情时更新暂缓，也可以点刷新按钮。

也可以显式指定项目启动：

```powershell
py -3.13 app.py --project "C:\path\to\contest-project" --open
```

## 边界与隐私

- 节点状态、关联和审查信息来自已有记录；缺失内容不会自动补造。哈希对比不能验证批准真实性，也不能代替 Harness 门禁、独立验证或最终交付检查。
- 文件哈希按当前内容重新计算；读取过程中检测到文件变化时显示待核。单个文件的哈希读取上限为 100 MB，超过时显示受限。
- 比赛文件和批准记录只读；手动登记的会话链接保存在工作台的 `data/` 目录，项目选择及查看偏好保存在当前浏览器。请勿将它们、比赛数据或凭据提交到公开仓库。
- 文件扫描最多覆盖 1500 个支持的文件和四层子目录；受数量、深度或读取限制时会提示。超过 20 MB 的文件不在页面预览。Word 和 Excel 预览不保证完整排版，公式不会重新计算。
- 服务仅监听本机并校验请求的本机地址；没有多人共享、工作台内聊天、求解任务执行或自动审批。逐章并行的真实比赛端到端使用、会话链接可访问性仍需实际验证。

## 开发检查

```powershell
py -3.13 -m unittest discover -s tests
node --test tests/*.test.cjs
```

测试验证软件行为，不构成比赛成绩、论文质量或交付通过的保证。
